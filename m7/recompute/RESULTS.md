# Independent Condorcet recomputation (2026-09-28)

**Status: Historical independent recomputation; the released m = 7 proof is checked by verify.sh.** No construction for Epoch's target exists for `4 <= m <= 7` according to the exact finite certificate below. For `m=3`, the whole candidate set is a CWS; for fewer candidates, a CWS of size at most three is trivial. This is not a claim about arbitrary `m`. The strongest published baseline I found is [Zilberstein et al., arXiv:2604.19851](https://arxiv.org/html/2604.19851v1): exact search through `m=6`, with a floating-point upper bound for `m=7`. An independently checked exact `m=7` certificate would improve that baseline; researchers searching for a finite counterexample could start at `m=8`.

## Definition and source comparison

[Epoch's problem](https://epoch.ai/frontiermath/open-problems/condorcet-winning-sets) has `n` voters with strict full rankings of `m` candidates. An outsider `c` *overthrows* committee `W` iff at least `n/2` voters place `c` above **every** member of `W`. Thus `W` is a Condorcet winning set (CWS) iff, for every `c` outside `W`, strictly fewer than `n/2` voters do that. An exact half is an overthrow. A probability distribution on rankings is equivalent for existence questions: rational feasible weights can be scaled to an integer electorate. This is also the formal `1/2`-undominated definition in Zilberstein et al., Definition 2.1-2.2, although prose in that paper uses “majority” loosely. The primary m = 7 certificate uses the same `>= n/2` overthrow predicate.

## Independent formulation and exact certificate

I wrote [independent.py](independent.py) before reading or running the primary builder's encoder, checker, or certificate. For each `k`-set `W` and `c` outside it, let `A[(W,c),p]=1` iff `c` is top-ranked within `W∪{c}` in ranking `p`. A profile with no size-`k` CWS exists iff there is one challenger choice `c(W)` for every `W` and a simplex vector `x >= 0`, `sum x=1`, satisfying `A[(W,c(W))]x >= 1/2` for every `W`. This checks the Epoch tie boundary exactly. The top `m-k` positions determine every entry of `A`; hence `m=7,k=3` has 840 distinct columns rather than 5040 redundant full-ranking columns.

For a selected set of challenger inequalities, an infeasibility core carries rational weights `λ_e >= 0`, `sum λ_e=1`, and `max_p sum_e λ_e A[e,p] < 1/2`. Summing the selected inequalities would give at least `1/2`, a contradiction. The checker recomputes the maximum over all prefix rankings with Python `Fraction`. Relabeling candidates preserves each inequality, so the checker generates each core's entire `S_m` orbit and asks an integer SAT solver whether every committee can choose a challenger while avoiding all certified cores. `m=7` needs only nine base cores (3-5 events each), generating 21,980 distinct learned clauses. A fixed first challenger is valid by relabeling. The independent SAT instance is UNSAT; the primary check uses CaDiCaL 1.9.5 through PySAT. A second check with Glucose 3 was also UNSAT in 45.56 s. The certificate is the base duals plus a deterministic checker of their orbit closure and SAT coverage; no floating-point solver result is trusted by the checker. A standalone SAT proof trace is not included, so the final UNSAT step depends on exact SAT solver recomputation.

The `m=6,k=3` control was generated by a separate recursive branch over challenger choices; its 896 rational dual leaves are checked without orbit assumptions. Padding any smaller counterexample with candidates ranked last would give an `m=6` counterexample, because CWS membership is upward closed. The `m=6,k=2` positive control has a verified six-voter rational profile (six rankings, each weight `1/6`); the `m=3,k=1` tie control is feasible too.
